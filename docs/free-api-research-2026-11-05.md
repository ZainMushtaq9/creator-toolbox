## Verdict vs AnyRouter (current default)
AnyRouter Free = $0, no credits, only a 5-request LIFETIME trial on anyrouter/free, then Go $2/mo (Polar charges $2.63) or a donated BYOK key (DeepSeek / Z.ai GLM / Moonshot Kimi). After 5 requests, free models return 403; paid models without credits return 402.
**Yes — Cloudflare Workers AI beats AnyRouter for THIS use case, clearly.** It is the only option that is (1) genuinely recurring-free forever with no card and no key, (2) native to the Worker the project already runs on, and (3) covers all three needs (instruction LLM, embeddings, long-context) from one provider. AnyRouter's only edge is model choice/frontier models behind one OpenAI-compatible endpoint — but that edge costs $2/mo or a donated key after 5 requests, which breaks the project's $0/no-card constraint. Keep AnyRouter as an OPTIONAL fallback (config + mock), not the default. Google AI Studio is the best external backup; Groq is the best free external instruction LLM; NVIDIA is a useful fallback with the widest catalog but trial-only terms.

## Ranked recommendations (BEST 1 per need)

### (a) Instruction LLM — BEST: Cloudflare Workers AI, @cf/meta/llama-4-scout-17b-16e-instruct
- Call: `env.AI.run('@cf/meta/llama-4-scout-17b-16e-instruct', { messages })` — no key, no secret.
- Free limit: 10,000 Neurons/day/account, resets 00:00 UTC, forever. 131K served context. Text gen ~300 RPM (UNVERIFIED officially).
- What the user must do: NOTHING extra — needs only the Cloudflare account the Worker already runs on (still an external blocker: no Cloudflare account exists yet for this project).
- Runner-up (external key, no card): Groq `openai/gpt-oss-120b` at https://api.groq.com/openai/v1 — 30 RPM, 1,000 req/day, 200K tokens/day; key from console.groq.com, prefix gsk_, no card.

### (b) Embeddings — BEST: Cloudflare Workers AI, @cf/baai/bge-m3
- Call: `env.AI.run('@cf/baai/bge-m3', { text })` — 1024-dim, multilingual, ~1,075 neurons/1M tokens.
- Free limit: same 10,000 Neurons/day pool; embeddings ~3,000 RPM (UNVERIFIED officially). Store vectors in D1/Vectorize (Phase 4/5 decision).
- What the user must do: nothing extra (same Cloudflare account as above).
- Runner-up (external key, no card): Google `gemini-embedding-2` at https://generativelanguage.googleapis.com/v1beta — 3072-dim, 8,192 input tokens; free tier, key from Google AI Studio, no card; exact RPM/RPD unpublished.

### (c) Long-context LLM — BEST: Google AI Studio, gemini-2.5-flash
- Call: POST https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent (or OpenAI-compatible base https://generativelanguage.googleapis.com/v1beta/openai/ — verify before wiring).
- Free limit: free tier, no card, no billing account; up to 1M tokens context — the longest verified free context in this review. Exact RPM/RPD NOT published by Google — verify in AI Studio rate-limit page before relying on a number.
- What the user must do: create a Google AI Studio account (Google account only) and generate an API key at aistudio.google.com; store as Worker secret (e.g. GEMINI_API_KEY). Free-tier prompts may be used by Google to improve products — do not send sensitive user data.
- Runner-up (no key at all): Cloudflare `@cf/meta/llama-4-scout-17b-16e-instruct` (131K served) or the Qwen3.8-27B family (262K, longest free window on Workers AI — confirm exact model ID against the live Cloudflare catalog before wiring).

## Suggested Phase 4 wiring
1. Primary: Cloudflare Workers AI for (a) + (b) + short/medium context — zero keys, zero cost, zero new accounts.
2. Long-context overflow: Google Gemini (gemini-2.5-flash, 1M ctx) behind a Worker secret, used only when input exceeds the Workers AI window.
3. Optional fallback (not default): AnyRouter (anyrouter/free) + Groq (gpt-oss-120b) + NVIDIA NIM, each behind its own Worker secret, only if the user supplies keys; keep the labelled dev mock until then.
4. Do NOT wire: GitHub Models (dead), Opencode/Kilo Code (not APIs), Ollama Cloud (no longer free), Cerebras (card required), Cohere trial (1,000 calls/mo, non-commercial only), Vercel Gateway (card status unresolved, $5/mo too small to be primary).
