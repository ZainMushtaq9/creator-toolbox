# CreatorToolbox Strategy (summarised)

Adopted business direction (2026-11-05). This is a summary of the strategy
document, not a claim that everything in it is built — see `docs/ROADMAP.md`
for what is actually done.

## Positioning

All-in-one tools platform. Primary audience: content creators first, website
owners second. Initial growth: SEO + AdSense. Differentiation: connected
workflows + privacy-first processing. SEO Intelligence is the later advanced
product, not the launch core.

Tagline: **Create. Optimize. Convert. Grow.**
Subhead: **Free online tools and AI-powered productivity for everyone.**

## Five pillars

1. Creator Tools — YouTube, Instagram, TikTok generators and calculators.
2. File and Media Tools — image compression, resize, conversion (local).
3. Productivity and Developer Tools — text, counts, calculations.
4. SEO Intelligence — later advanced product (keyword research, audits,
   competitor analysis, Search Console, AEO/GSO). Owner-only.
5. AI Productivity — AI helpers, honestly labelled (template vs AI vs
   calculation). Stage 1 generators use templates, not AI.

## Five principles

1. Free core tools with no subscription required — and transparent limitations
   (do NOT claim "100% free forever").
2. Privacy-first local processing.
3. No unnecessary signup.
4. Workflow-oriented (tools connect; results save to workspaces).
5. Honest AI (label template vs AI vs calculation).

## Product shape

- **Workflows**: one topic carried across tools. Stage 1: YouTube Creator
  Workflow is fully working; Instagram, Blogger, Developer, Student, Small
  Business and Website Owner workflows are guided tool sequences.
- **Workspaces**: save results into projects. Stage 1: browser localStorage
  only — no signup, no account sync yet. Export as JSON.
- **Collections**: 8 curated kits (YouTube Starter, Instagram Growth,
  Blogger SEO, Website Launch, Developer Starter, Image Optimization,
  Student Productivity, Small Business).
- **50 future tools**: Stage 2/3 candidates in `frontend/src/config/futureTools.js`
  (SEO + developer tools prioritised). Not built, not listed as working tools.

## Monetization (priority order)

1. AdSense first (after approval — not guaranteed).
2. Affiliate (later).
3. Digital products (later).
4. Sponsored (later).
5. Premium — much later, optional; core tools stay free.

No affiliate links or paywalls in Stage 1.

## International

One global site. No duplicate country pages.
